# Phase 03B.2 — staff assignments and additional event media

Status: implementation candidate; runtime checks pending. Baseline: Phase 03B.1 commit 01389ad07366ec419e80141fdee420569c0c6fb7; user reported 54 passing backend tests and hosted CI passed.

- Occurrence-local optional collector and reviewer; only Administrator/Editor (manage_all_occurrences) may assign. Assignment selection is limited to active staff from eligible baseline groups; writes also check actual effective permissions. Collector access extends to assigned drafts, in addition to existing creator access. Reassignment removes that delegated access; creator access remains. Reviewer assignment restricts review/return/reject/verify actions to that reviewer, while the existing reviewer read scope for non-drafts is unchanged. Reassignment requires an active draft, returned, submitted or under-review occurrence. No assignment of inactive staff, same collector/reviewer or known contributor.
- Self-review excludes event creators, current submitters/collectors and actors recorded in existing audit events for edits, submission, additional ticket prices and attachment changes. The exclusion is deliberately conservative across the recurring series, since siblings may share metadata and copied content. Existing historical audit rows are reused. If a reviewer loses privileges, a manager must reassign them; account privileges are evaluated per request.
- Attach up to 12 existing active photos/posters, ordered independently of the main poster; no binary duplication. Draft/returned edits only; archived attachments are blocked at submission/verification. Existing verified history may retain links to archived images; current media content access policy still applies. Repeat generation copies attachment links, but does not inherit staff assignments. Shared event metadata still cannot be edited across multiple occurrences. No direct upload or storage migration in this slice.
- Assignment changes and image link changes use version checks, transactions and audit history. Six new backend tests. Expected cumulative count: 60.
