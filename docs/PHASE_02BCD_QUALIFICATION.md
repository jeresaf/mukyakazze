# Phase 02B–02D — directory candidate

Adds countries, cities, areas, venues and promoters. Seeds Uganda and Kampala only; other locations must be entered by staff, not inferred from the mock workbook. No fictional events or private workbook data are included. Venue coordinates are optional, must be a pair and in range. Parent relations are fixed after creation; archive and replace mistaken records before linking events. Case-insensitive uniqueness is scoped by parent where relevant. The API prevents archiving parents with active children and restoring children of archived parents; PostgreSQL advisory locks serialize directory mutations. Future event module must participate in these invariants before adding references.

Administrators and Editors can manage directory records and view internal contacts; other baseline roles can read non-contact metadata. Contacts are omitted from read-only API responses and contact values are not copied to audit details. Audit events record changed field names and versions. No hard deletes through the API. Public contact consent, future public projections, contact export, sponsor/media support and event data collection are deferred.
