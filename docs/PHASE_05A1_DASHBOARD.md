# Phase 05A.1 — Workspace shell and operational overview

Candidate against Phase 04G (GitHub 16b3d05); frontend only, no migration or new dependency. Preserve all server-side permissions, workflow logic and existing record forms. Grouped collapsible navigation and mobile menu; no fake data. Overview provides scoped totals, status breakdown, shortcuts, latest chronological issue and its live revision-bound readiness, my assigned collection count and assigned submitted review count. Calendar uses Kampala editorial dates, actual local clock times, non-cancelled scoped results; week starts Monday for navigation (publication week remains Thursday to Wednesday). Calendar is read-only. New event quick action opens a draft form, not a save. Error and loading states never substitute zero for unavailable figures. No personal data or secrets committed. Existing recovery account guidance remains in effect.
