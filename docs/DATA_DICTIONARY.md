# Data dictionary
The companion workbook_mapping.csv records the exact 26 Events headers, 27 Issue settings, other sheet headers and dashboard/help coverage. Source sheets are How To Use, Issue, Dashboard, Events, Feature Tips, Coming Up and Lists. Formula helpers are never operational input. Use source file digest and cell/row provenance; no row-based identifier is authoritative.

Core types: UUID identifier; text trimmed without loss of meaningful content; local editorial date; aware actual start/end timestamps; nullable integer UGX; strict booleans and enums; references to catalog and controlled media assets. For submitted/verified data require original mandatory event fields. Blank prices are UNKNOWN; zero is FREE only when unconditional; retain note and tier. Preserve source status/initials separately when migration cannot establish a verified actor. Original photo path is provenance only, never read directly by server. Settings such as Website/WhatsApp may be display text, not necessarily valid URLs; distinguish labels from link fields. Reject formulas in editable raw inputs and ignore generated formulas. Legacy defaults must be explained in import report.

See DATABASE_DESIGN.md for entity relationships, WORKFLOWS.md for rules, and evidence/baseline.json for the sample baseline. Extended description, city, country, coordinates, source, rights, public/private contact, cancellation and audit are proposed production additions, not original workbook columns.
